# Layer 3 signal collector - supply chain and procurement

Collects dated, sourced supply-chain and procurement signals: buyer-supplier deals, capacity and
facility commitments, power procurement, government awards, orders and backlog, supplier
disclosures. Discovery only: nothing here prices, tiers or judges a stock.

Funding rounds, IPOs and pure M&A are Layer 4 events. Items that only match those are stored
but not kept as Layer 3 signals (they are listed in the weekly `11_layer4_crossref.csv`).

```
layer3-signal-collector/
  layer3_daily.py       DAILY collector (SEC + SEC full-text + feeds; wholesale store, then keyword combinations)
  layer3_weekly.py      WEEKLY packet builder (consolidate, USAspending, SAM, ERCOT, convergence, coverage)
  l3lib.py              shared helpers and the signal engine (vocabulary groups + combination rules)
  config/
    keywords.json       vocabulary groups, combination rules, veto sentences, full-text queries, thresholds
    buyers.csv          buyer / counterparty registry (hyperscalers, AI labs, chipmakers, agencies, utilities)
    sectors.csv         the 26 canonical sectors and tagging keywords
    ticker-sectors.csv  tracked universe: ticker -> sectors
    feeds.csv           generated by tools/build_feeds.py (enabled feeds + agent-covered blocked feeds)
  tools/build_feeds.py  regenerates feeds.csv (static feeds + Google News queries from sector words)
  triggers/             daily.txt / weekly.txt: pushed by the claude.ai kick-off routines
  data/
    daily/sec/<date>/   filings.jsonl, index_summary.json, _done.json
    daily/fts/<date>.jsonl, daily/feeds/<date>.jsonl, daily/health/<date>.json
    weekly/<Monday>/    the packet (15 datasets, coverage.json, SUMMARY.md, packet.xlsx)
    run-log.csv
```

## Two layers of capture

1. **Wholesale.** Every filing and feed item that is reachable is stored with date, source and
   link before any filter: all 8-K / 6-K filings of the day are indexed (those with a gated item
   are opened, with EX-99 / EX-10 exhibits), 10-Q / 10-K of the tracked universe and buyers are
   read, SEC full-text search covers the high-yield phrases for any filer, and every feed item is
   stored.
2. **Keyword combinations.** Each stored item is analysed sentence by sentence. A combination
   fires only when its parts sit in the same sentence (or sentence plus the next): an action verb
   + a contract object + a dollar or MW / GW / wafer figure + a physical or power or government
   context word; a registry buyer named with a contract object; facility event + capacity term +
   figure; power term + contract object + MW / GW; government term + award verb + dollars;
   backlog term + figure; customer or supplier concentration with a share. Score = strongest
   combination + 1 per further distinct combination (max +3); kept when score >= 3. Boilerplate
   and financing sentences are skipped (`sentence_veto`).

Binding status (executed / non-binding / mixed / unstated) is read from the sentences that fired.

## What runs when

| Job | When (New York) | Started by | Writes |
|---|---|---|---|
| Daily collector | Every day 11:30 PM | routine 00a pushes `triggers/daily.txt` -> GitHub Action `Layer 3 - daily collector` | `data/daily/...` |
| Weekly packet | Wednesday 12:00 AM (window Tuesday-Monday) | routine 00b pushes `triggers/weekly.txt` -> GitHub Action `Layer 3 - weekly packet` | `data/weekly/<Monday>/` |
| Routines 01-04 | Wednesday 1:00-4:00 AM | claude.ai routines | `research/layer 3/signal-discovery/<end-date>/` |

Manual run from this folder:

```
python tools/build_feeds.py                 # after editing sectors.csv or the feed list
python layer3_daily.py                      # last 3 business days of SEC + full-text + feeds
python layer3_daily.py --only sec --date 2026-10-14 --sec-limit 25
python layer3_weekly.py                     # window = Tuesday-Monday ending on the last Monday
python layer3_weekly.py --skip-slow         # no USAspending / SAM / ERCOT calls
```

Requirements: Python 3.10+, `openpyxl`. Network: sec.gov (descriptive User-Agent set in
`l3lib.py`), efts.sec.gov (full-text), api.usaspending.gov, ercot.com, wire / trade-press /
government RSS, news.google.com. Optional: environment variable `SAM_API_KEY` (free key from
sam.gov) for SAM.gov award notices.

## Source reachability (tested 2026-10-15 from a Windows workstation)

| Source | Result | In the design |
|---|---|---|
| SEC daily index, filings, EX-99 / EX-10 | works | daily, wholesale |
| SEC full-text search (efts.sec.gov) | works | daily, high-yield phrases |
| USAspending API (`spending_by_transaction`) | works, no key | weekly |
| SAM.gov opportunities API | 404 without an API key; free key required | weekly if `SAM_API_KEY` set, else agents |
| ERCOT large-load page | page reachable; lists documents, not named parties | weekly document watch; agents read them |
| PJM | interconnection page moved; data miner needs a subscription key | agents |
| PR Newswire RSS | works (follows a 301) | daily |
| GlobeNewswire, Business Wire (feed id), FERC, DoD contracts, GovConWire, Mining.com, Commerce | 403 / empty from a scripted client | disabled in feeds.csv, covered by routine 03 |
| Trade-press, buyer-newsroom, NASA / DOE / EIA / service-news RSS | 30 of 45 tested reachable | daily |
| Google News RSS | works (lead source only) | daily, rotated sector queries |

These results were obtained from a workstation, not from GitHub Actions runners. Layer 4's
first run saw Cloudflare challenges from GitHub addresses on some trade-press feeds
(The Quantum Insider, GovConWire), so the first scheduled runs should be checked against
`data/daily/health/<date>.json` (`feeds` failures) and the feed list adjusted.

## Known limits (stated, not hidden)

- Keyword combinations find what is phrased in recognisable words; the cross-sector routine is
  the backstop for the rest.
- SEC full-text search is an undocumented endpoint; it may change. A failure is logged in the
  daily health file and the sec module keeps working without it.
- The weekly USAspending sweep caps queries (`--usa-budget`, default 160) and reports when the
  budget stopped a batch.
- 10-Q / 10-K are read only for tracked universe companies and the buyer registry; other
  filers' periodic reports are reached only through full-text hits.
- Registration statements (S-1 / F-1 / 424B4) are kept only with a sector-relevant supply
  disclosure and are always marked as a Layer 4 cross-reference.
